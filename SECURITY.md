# Security

This repository is a snapshot of Seira from the Y Combinator agent hackathon (October 2026). It is no
longer developed, but security problems are still fixed on `main`.

## Reporting a vulnerability

Use **Report a vulnerability** on this repository's **Security** tab. The report stays private between
you and the maintainers. Please don't open a public issue or pull request for a security problem.

Say what is affected, how to reproduce it, and what an attacker could do with it.
